# Security

Report a security problem in this pack privately, through
[GitHub's private vulnerability reporting](https://github.com/Mynster9361/maester-pack-lpms/security/advisories/new),
not in a public issue. The same link is the pack's `SecurityContact` in `maester-pack.json`.

A problem in the LeastPrivilegedMSGraph module goes to
[Mynster9361/Least_Privileged_MSGraph](https://github.com/Mynster9361/Least_Privileged_MSGraph/security), and a
problem in Maester itself to [maester365/maester](https://github.com/maester365/maester/security).
